# Global Banking Analytics — Project Presentation Guide

## Opening
> My project is a Global Banking Analytics dashboard created using Power BI. The objective was to transform banking data into an interactive report that helps users understand overall financial performance, customer behavior, and risk exposure.

## Dataset
The dataset contains customer, bank, branch, account, loan, transaction, credit-score, customer-segment, customer-status, and risk information covering 2024–2026.

## Dashboard 1 — Executive Overview
> The first dashboard provides a high-level view of the banking portfolio.

Explain the KPIs:
- Total Customers
- Total Balance
- Total Loan Amount
- Transaction Value
- Average Credit Score

Explain the visuals:
- Transaction Trend shows changes in transaction activity.
- Customers by Bank compares customer distribution.
- Customer Segment shows the composition of customers.
- Account Type identifies the most common banking products.
- Bank Performance Summary provides a single comparison table.

**Business value:** executive reporting, bank comparison, and high-level performance monitoring.

## Dashboard 2 — Customer & Risk Analysis
> The second dashboard moves from overall performance into customer intelligence and risk analysis.

Explain:
- Average Age
- Average Credit Score
- At Risk Customers
- High + Critical Risk

Then explain:
- Risk Category shows the size of each risk group.
- Customer Status shows lifecycle distribution.
- Risk by Bank compares risk composition between banks.
- Segment vs Risk identifies differences in risk concentration across customer segments.

**Business value:** customer risk monitoring, credit analysis, segment analysis, and bank-level risk comparison.

## Dashboard 3 — Loans & Transaction Analytics
> The third dashboard focuses on lending and transaction behavior.

Explain:
- Loan portfolio
- Loan status
- Loan types
- Transaction types
- Transaction channels
- Branch performance
- Monthly transaction trends

**Business value:** lending analysis, transaction monitoring, channel analysis, and branch comparison.

## Interactive Features
The report uses Power BI slicers and cross-filtering. Users can select banks, segments, risk categories, statuses, branches, accounts, loans, or date ranges and see the relevant KPIs and visuals update dynamically.

## Closing
> The main learning from this project was that dashboard development is not only about creating charts. The important part is selecting metrics and visuals that answer meaningful business questions. I structured the report from overall performance to customer and risk analysis, followed by lending and transaction analysis.
